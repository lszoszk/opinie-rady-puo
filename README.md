# Opinie Rady do Spraw Przeciwdziałania Unikaniu Opodatkowania – wyszukiwarka

Wyszukiwarka 74 uchwał Rady PUO (opinie dotyczące GAAR i ograniczenia korzyści umownych, kadencje I–III, 2019–2026) na poziomie punktów uzasadnienia: fasety (rozstrzygnięcie, schemat optymalizacyjny, podatek, kadencja, rola punktu, warunek), serie podobnych uchwał, cytowania, podgląd PDF z podświetleniem fragmentu.

Źródło: https://www.gov.pl/web/finanse/prace-rady2 (pobrane 17.11.2026). Tekst skanów z OCR (Tesseract) – przy cytowaniu sprawdź w PDF. Opisy zespołów czynności i typy schematów to opracowanie (reguły + model językowy, z dosłownymi cytatami jako dowodem), nie treść uchwał.

Wersja statyczna: wyszukiwanie działa w przeglądarce (`static-api.js`, dane w `data/`).
